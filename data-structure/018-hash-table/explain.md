# Hashing функц

Та бодлоготой [энд] танилцаж болно .

## _Бодлогын өгүүлбэр_

Бид энэ удаад hashing хэмээх ойлголттой танилцах болно . Бидний ойлгосноор hashing нь time complexity -r O(1) болгож өгдөгөөрөө онцлог гэж ойлголоо . Hashing -д object -ийн key value хэлбэрээр хадгалдаг чухал үүрэгтэй . Object -д хадгалах key-г хашлаад object -д хадгална . Энэ тохиолдолд орж ирсэн давхцаж болох бөгөөд үүнийг collision гэж нэрлэнэ .
Энэ тохиолдолд бид collision үүсгэхгүй байх арга хэмжээ авах ёстой .
